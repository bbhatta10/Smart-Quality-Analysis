## Smart Manufacturing Quality Control & Predictive Insights

This project is my end-to-end exploration of how data can help improve product quality in a manufacturing environment. I used real production and inspection data to understand defects, build simple predictive models, and design an interactive dashboard that highlights where problems occur and why.

## ⭐ What This Project Does 

* Gives a clear overview of factory quality performance
* Finds patterns behind defects (shift, inspector, location, defect type)
* Predicts which batches are likely to fail
* Helps identify high-risk or severe defects before they happen
* Includes a clean, interactive Tableau dashboard

## 🔍 Key Components

### 1. Exploratory Data Analysis

I explored defect trends, quality scores, shift performance, and inspector patterns.
This helped reveal:

* Cracking & major_crack are the most common defects
* Night shift tends to show more issues
* A few inspectors and locations contribute more defects

###  2. Machine Learning Models

Three simple models:

* **Defect likelihood prediction**
* **Severity prediction**
* **Quality score forecasting**

All outputs are exported as CSV files for easy dashboard use.

###  3. Smart Quality Dashboard

A combined “Factory Overview + Root Cause Analysis” dashboard showing:

* Total defects
* Average quality score
* Defect per batch
* Defects by weekday, inspector, location, type
* Shift-based filtering

## 🛠️ Tools Used

**Python, Pandas, Scikit-Learn, Seaborn, Matplotlib, Jupyter, Tableau**


##  Why This Project Matters

This project shows how data can help reduce defects, identify operational issues, and support quality improvement in manufacturing.
It combines practical analytics + ML + dashboarding in one workflow.
